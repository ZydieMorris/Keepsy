# Keepsy Design System

## Design Overview

Keepsy is a private photo-sharing and gallery application focused on personal memories, privacy, and controlled sharing.

The visual design should feel:

- Warm
- Minimal
- Premium
- Personal
- Private
- Modern
- Calm

The interface should support the photos rather than compete with them.

> **Your memories. Your people. Your space.**

---

# Brand Identity

## Brand Name

**Keepsy**

### Brand Meaning

Keepsy represents:

- Keep
- Memories
- Personal moments
- Sharing with people you trust

### Brand Direction

Keepsy should feel like a combination of:

- A modern photo gallery
- A private digital photo album
- A personal memory journal

The product should NOT feel like:

- A social media platform
- A generic file manager
- A business dashboard
- A traditional CRUD application
