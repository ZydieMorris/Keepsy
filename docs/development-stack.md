# Project Context

## Project Overview

**Keepsy** is a web-based private photo-sharing and gallery application designed to give users a secure and personal space to store, organize, and share their photos with selected people.

Users can upload and organize their personal photos into albums, then invite other users to access specific albums. Invited users must accept the invitation before they can view the shared photos.

The application focuses on **private photo sharing**, giving users control over who can access their memories rather than making photos publicly accessible.

Keepsy is intended to provide a simple, modern, and secure alternative to publicly oriented social media platforms for users who want to share personal memories with family, friends, or other trusted people.

---

# Project Type

The application is a **Web-Based Private Photo Gallery and Sharing Platform** with **Album Management**, **User Invitations**, **Access Control**, and **Photo Sharing** capabilities.

The system is designed for individuals and groups who want to privately store and share photos with selected users.

---

# Project Objectives

- Provide users with a private space to store and manage personal photos.
- Allow users to organize photos into albums.
- Allow album owners to invite other registered users.
- Require invited users to accept invitations before gaining access.
- Provide controlled access to shared albums.
- Allow users to easily browse and view shared photos.
- Protect private photos from unauthorized access.
- Provide a clean and modern photo-gallery experience.
- Build a scalable and maintainable application using modern software development practices and technologies.
